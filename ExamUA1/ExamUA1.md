# Examen UA 1

Objectif : L'objectif de cet examen est de trouver une façon de rentrer dans la machine ExamUA1 et d'extraire le contenu du fichier nommé CTF dans la machine cible. Vous avez le droit d'utiliser Internet et l'intelligence artificielle. Vous devez documenter toutes les étapes avec des explications et des captures d'écran. Si vous ne donnez pas d'explications, vous allez perdre des points. 

**Note : Dans vos captures d'écran, je veux voir le nom de votre machine virtuelle.**

## 1. Reconnaissance

* Scanner le réseau et trouver les machines qui sont connectées au réseau.
* Identifier la machine cible.
* Scanner les ports ouverts de la machine cible.
* Scanner les versions des services qui tournent sur les ports.

## 2. Exploitation
* Trouver une méthode pour obtenir l'accès à la victime et documenter la procédure.

## 3. Mission : Extraction du flag (Machine cible)
* Transférer le texte écrit dans le fichier « secret » sur votre machine Kali et documenter la procédure.
