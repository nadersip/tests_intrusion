# ✍️ Examen UA 1

## 🎯 Objectif
 
 L'objectif de cet examen est de trouver une façon de rentrer dans la machine ExamUA1 et d'extraire le contenu du fichier nommé CTF dans la machine cible. Vous avez le droit d'utiliser Internet et l'intelligence artificielle. Vous devez documenter toutes les étapes avec des explications et des captures d'écran. Si vous ne donnez pas d'explications, vous allez perdre des points. 

Dans l’examen, vous allez appliquer tout ce que nous avons vu en classe :

* Effectuer des scans avec **Nmap** 
* Effectuer du **brute force** sur un mot de passe 
* **Déhasher** un mot de passe 
* Extraire des informations à partir de la **machine victime**


**Note : Dans vos captures d'écran, je veux voir le nom de votre machine virtuelle.**

## 🔭 Reconnaissance

* Scanner le réseau et trouver les machines qui sont connectées au réseau.
* Identifier la machine cible.
* Scanner les ports ouverts de la machine cible.
* Scanner les versions des services qui tournent sur les ports.

## ⚔️ Exploitation
* Trouver une méthode pour obtenir l'accès à la victime et documenter la procédure.

## 🏆 Mission : Extraction du flag (Machine cible)
* Transférer le texte écrit dans le fichier « secret » sur votre machine Kali et documenter la procédure.
