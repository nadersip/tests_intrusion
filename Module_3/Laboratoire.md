# 🧪 Lab 3 : NetCat et CTF

## 🎯 But du Lab

L’objectif de ce laboratoire est de mettre en pratique les techniques de reconnaissance réseau et d’exploration d’une machine Linux à l’aide de l’outil nc (Netcat). Les étudiants devront identifier les services accessibles, déterminer un chemin permettant d’accéder à la machine Ubuntu, puis localiser et extraire le contenu d’un fichier CTF afin de valider leur progression.
