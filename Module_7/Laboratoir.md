# 🧪 Lab 7 : # BeEF Framework


## 🎯 But du Lab

L’objectif de ce laboratoire est de vous familiariser avec BeEF (Browser Exploitation Framework) en réalisant une simulation contrôlée d’injection d’un hook dans une page Web.

Vous devrez intégrer un hook BeEF dans une page Web, puis faire visiter cette page par un client afin d’établir une connexion avec le navigateur de la machine victime.

Une fois la connexion établie, vous devrez explorer les différentes fonctionnalités de BeEF et démontrer les actions qu’il est possible d’effectuer sur le navigateur de la machine victime

Machine victime : Vous pouvez utiliser la machine virtuelle Windows 7 (Win7).
