# 🧪 Lab 3 : # Metasploit Framework (MSF)


## 🎯 But du Lab

L’objectif de ce laboratoire est de se familiariser avec l’outil Metasploit en réalisant une exploitation contrôlée de la machine vulnérable Metasploitable. Vous devrez identifier une vulnérabilité exploitable, sélectionner et configurer un exploit approprié, puis l’utiliser afin d’obtenir une session sur la machine cible.
