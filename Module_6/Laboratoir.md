# 🧪 Lab 6 : # Metasploit Framework (MSFvenom)


## 🎯 But du Lab

L’objectif de ce laboratoire est de se familiariser avec msfvenom et le Metasploit Framework en réalisant une simulation contrôlée d’infection d’un logiciel. Vous devrez générer un payload, l’intégrer à l’application PuTTY, transférer le logiciel modifié vers une machine Windows de laboratoire, puis configurer un multi/handler afin d’établir une connexion avec la machine cible et d’observer le fonctionnement d’une session distante.
