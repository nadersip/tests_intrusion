# 🧪 Lab 8 : DirBuster et CTF


## 🎯 But du Lab

L’objectif de ce laboratoire est de vous familiariser avec l’outil DirBuster en effectuant une analyse du site Web de la machine victime.

Vous devrez utiliser DirBuster pour découvrir les répertoires et les ressources accessibles sur le serveur Web, identifier une piste permettant d’exploiter une vulnérabilité et tenter d’obtenir un accès à la machine victime afin d’en extraire le contenu du fichier CTF.

Machine victime : La machine victime est cachée et n’est pas directement accessible dans votre environnement.

Vous devez suivre les étapes suivantes :

Démarrer votre machine TCRouter en premier.

Une fois votre TCRouter démarré, demander au professeur de démarrer la machine victime.
